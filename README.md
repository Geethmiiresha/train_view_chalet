# 🚂 Train View Chalet - Hotel Management System

A robust, web-based software application engineered to transform the operational landscape of the Train View Chalet property. This system serves as a centralized digital environment where customers, staff, and administrators interact to manage daily hotel operations, room inventory, and guest reservations effectively.

---

## 🚀 Features

*   **Customer Module (Booking & Requests):** Provides an accessible portal for guests to browse room availability, register personal accounts, and initiate booking requests. Includes a "Customer Request Form" for specific requirements like dietary needs or transport.
*   **Staff Interface:** Allows authorized staff members to monitor incoming booking requests and access customer details to deliver personalized hospitality.
*   **Admin Panel (Management Dashboard):** Command center featuring a comprehensive dashboard with visual analytics on total bookings, pending approvals, and user counts. Admins can manage room listings, update pricing, and handle the "Approve/Reject" workflow.

---

## 🛠️ Tech Stack & Tools

This project was built using the following technologies:

*   **Frontend:** HTML, CSS, JavaScript (Responsive, user-friendly interface)
*   **Backend:** PHP (Server-side scripting, form submissions, login security)
*   **Database:** MySQL (Relational database management for system records)
*   **Development Model:** Waterfall Development Model (Linear and sequential approach)

---

## 📊 System Architecture & Database

*   **Database Design:** Normalized database structure covering `Users`, `Rooms`, and `Bookings` tables to ensure data integrity and prevent double bookings.
